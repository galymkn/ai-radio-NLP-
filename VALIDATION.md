# Проверка после ревью — 26 ноября 2026

## Автоматические проверки

26 тестов проходят. Новые регрессии проверяют:
- После 3 ошибок сюжет получает failed, освобождая очередь следующему; лимит сохраняется после переподключения и поступления новых статей.
- Backoff 120 секунд и ручной retry-failed.
- Нормализация выключена по умолчанию и включается только явно.
- Демо успешно запускается повторно после принудительного истечения TTL первого выпуска.
- Выдача клипа не считается стартом; первый ACK фиксируется один раз.
- Экспорт включает исходные тексты, а пустые метки не считаются отрицательными.

Исходное офлайн-демо по-прежнему создаёт 5 клипов из 7 статей. В каждом запуске теперь новый каталог, повтор включён, cooldown равен нулю. Предыдущие каталоги остаются для просмотра/удаления вручную.

## Реальная сеть

Все 10 настроенных источников вернули HTTP 200, данные успешно разобраны. Отдельный Edge TTS запрос создал речевой MP3 (4.86 секунды).

Затем выполнен живой прогон collect → cycle → FastAPI TestClient:
- Получено и сохранено 117 статей из 10 источников.
- Hash-encoder создал 95 кластеров. Это наблюдаемое количество, не оценка качества.
- Extractive-редактор и настоящий Edge TTS создали 2 речевых клипа (лимит установлен намеренно).
- Главная страница, выдача аудио и подтверждение старта вернули 200.
- В live-annotations.json экспортированы 50 реальных статей, 3 предложения с источниками и 1 событие старта. Метки gold_story и supported пустые. Качество не оценено.

Проверка выполнялась с fetch_fulltext=false: сетевое извлечение полных страниц не проверено. Сервер проверен через TestClient, не через живой браузер или публичный порт. Звук получен и обработан ffmpeg; качество произношения не оценивалось на слух. ffmpeg взят из imageio-ffmpeg через FFMPEG_BINARY.

## Что остаётся непроверенным

Claude API (ключ отсутствует), MTProto (сессия отсутствует), живой Postgres, Docker, SBERT, публичный /stream и 24-часовой прогон. Результаты живого прогона НЕ означают, что производственный режим claude+sbert проверен.

Нет ручных метрик качества. Выборка последних 50 статей не репрезентативна для всего потока; перед слайдом с метриками требуется редакционная разметка.
